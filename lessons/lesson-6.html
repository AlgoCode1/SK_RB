6. Финальные штрихи для игры

Заканчиваем проект платформер

Финал Скрипты Нанесение урона

1 Нанесение урона

Предварительно, создай Script с именем Dmg в папке со всем скриптами

📄 Скопируй в Script (Dmg) 

workspace.Part_Dmg.Touched:Connect(function(hit)
    local humanoid = hit.Parent:FindFirstChildOfClass("Humanoid")
    if humanoid then
        humanoid:TakeDamage(5)
    end
end)

2 ↑ Увеличение скорости вращения

Внимательно проверь что скрипт - SpeedUp

📄 Скопируй в Script (SpeedUp) 

workspace.SpeedUp.Touched:Connect(function(hit)_     
    local humanoid = hit.Parent:FindFirstChildOfClass("Humanoid")
    if humanoid then
        workspace.Rot_Plat.Base.HingeConstraint.AngularVelocity = 20
    end
end)

3 ↓ Уменьшение скорости вращения

    local humanoid = hit.Parent:FindFirstChildOfClass("Humanoid")
